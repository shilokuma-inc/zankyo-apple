# サンプル楽曲の生成

アプリに同梱するサンプル楽曲 8 曲（`Zankyo/SampleSongs/`）を作るスクリプト。音源・譜面（Easy / Normal / Hard）・ジャケットを、
取り込んだ譜面と同じ形の ZIP（`Info.dat`・難易度譜面・`song.egg`・`cover.png`）にまとめ、一覧 `SampleSongs.json` を書き出す。
アプリは初回起動時に、この ZIP をライブラリへ入れる（`SampleSongInstaller`）。

## 曲と権利

| 曲 | 作曲 | 根拠 |
| --- | --- | --- |
| 歓喜の歌 | ベートーヴェン（1827 年没） | 没後 70 年を過ぎた曲の旋律 |
| エリーゼのために | ベートーヴェン（1827 年没） | 同上 |
| 山の魔王の宮殿にて | グリーグ（1907 年没） | 同上 |
| カノン | パッヘルベル（1706 年没） | 同上 |
| メヌエット ト長調 | ペツォールト（1733 年没。かつてはバッハの作とされた） | 同上 |
| きらきら星 | フランス民謡（18 世紀） | 同上 |
| ネオン・ドライブ | Claude（AI）によるオリジナル | このリポジトリのために作曲 |
| 斬響ラッシュ | Claude（AI）によるオリジナル | 同上 |

- 使っているのは旋律（楽譜）だけ。既存の演奏・録音（演奏者やレコード会社の権利がある）や、現代の出版譜・編曲は使っていない。
  音はすべてこのスクリプトで合成している
- 伴奏・変奏・後半の展開・譜面は、このスクリプトのための編曲（Claude による AI 生成）
- アプリの画面（曲名・作曲者・マッパー）には AI 生成の表記を出さない。作曲者は「ベートーヴェン」などの作曲者名、オリジナルとマッパーは「斬響」とする
- BeatSaver の譜面・音源は含まない（`docs/beatsaver-import-route.md` の「同梱しない」の前提のまま）

## 作り直す

Python 3.9 以降（標準ライブラリだけ）と、Ogg Vorbis のエンコーダーが要る。エンコーダーはアプリが使っている vorbis-swift / ogg-swift のソース
（Xcode で一度ビルドすると `SourcePackages` に取得される）からビルドするので、外部からのダウンロードは要らない。

```bash
scripts/sample-songs/build-encoder.sh <DerivedData>/SourcePackages /tmp/vorbis-encoder
python3 scripts/sample-songs/generate.py --encoder /tmp/vorbis-encoder
```

- 1 曲 10 秒ほどで作れる。`--only <slug>` でその曲だけ作り直せる（一覧は書き換えない）
- 同じスクリプトからは同じファイルができる（ドラムの雑音の種・ZIP の日時・Ogg のストリーム番号を固定している）
- 譜面を変えると譜面ハッシュ（ライブラリの ID）が変わる。すでにサンプルを入れた端末には、古いハッシュの曲が残る

## 構成

| ファイル | 内容 |
| --- | --- |
| `songs.py` | 8 曲の楽譜（旋律・和音）と編曲（区間ごとの楽器・伴奏・ドラム） |
| `notation.py` | 楽譜を文字で書く記法（`F#4/1` = F#4 の 4 分音符）。小節の拍数の合計を確かめる |
| `arrangement.py` | 楽器の音色と、ベース・アルペジオ・ドラムの刻み方。区間を並べて 1 曲を描き出す |
| `synth.py` | 1 周期分の波形の表を読み出すシンセサイザーと、ドラムの音。ディレイをかけて 16 ビットのステレオにする |
| `chart.py` | 旋律から譜面を作る。難易度ごとに間隔（Easy 1.3 秒・Normal 0.75 秒・Hard 0.4 秒以上）を空けて音を選び、旋律の上がり下がりで振る向きを決める |
| `cover.py` | ジャケット画像（ネオンの太陽と床の格子） |
| `generate.py` | 全体をまとめて ZIP と一覧を書き出す |
| `build-encoder.sh` | libvorbis の `examples/encoder_example.c` を、品質 0.3（約 112kbps）・ストリーム番号固定でビルドする |
